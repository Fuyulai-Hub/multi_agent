# 订单金额计算与校验服务（order-pricing）需求文档

## 1. 背景与目标

为电商结算链路提供一个可复用的订单金额计算与校验服务库，供下单、支付、对账等场景调用，要求金额计算零精度误差、规则可测试、异常可追溯。

## 2. 技术约束

- 语言：Python 3.9+，交付形态为可通过 `import order_pricing` 使用的库
- 技术选型偏好：纯标准库实现，零第三方依赖；金额计算使用 Decimal 保证精度
- 所有对外函数对非法输入统一抛出 ValueError（不允许静默返回）

## 3. 功能点

### FP-01 金额解析 parse_amount
- 描述：将用户输入的金额字符串解析为两位小数的 Decimal 金额
- 输入：text: str
- 输出：Decimal（两位小数，ROUND_HALF_UP）
- 规则：容忍前后空白与 ¥/￥ 前缀；支持千分位分隔符；非法格式（含错误分组、字母）抛 ValueError；非字符串抛 ValueError
- 样例：`"¥1,234.5"` → `1234.50`；`"0"` → `0.00`
- 类别：功能

### FP-02 会员折扣 apply_discount
- 描述：按会员等级计算折扣后金额
- 输入：amount: str|int|float|Decimal, level: str
- 输出：Decimal（两位小数）
- 规则：NORMAL→1.00，SILVER→0.95，GOLD→0.90，VIP→0.80；等级不区分大小写；未知等级抛 ValueError；金额为负抛 ValueError；结果四舍五入到分
- 样例：`("100", "VIP")` → `80.00`；`("99.99", "SILVER")` → `94.99`
- 类别：功能

### FP-03 运费计算 calc_shipping
- 描述：按重量与地区计算运费
- 输入：weight_kg: str|int|float|Decimal, region: str
- 输出：Decimal（两位小数）
- 规则：首重 1kg（含）内 10 元；超出部分每 500g（不足 500g 按 500g 计）加收 5 元；新疆/西藏地区额外加收 15 元；重量≤0 抛 ValueError；地区为空或非字符串抛 ValueError
- 样例：`("0.5", "北京")` → `10.00`；`("1.5", "上海")` → `15.00`；`("1.0", "西藏")` → `25.00`
- 类别：功能

### FP-04 优惠券校验 validate_coupon
- 描述：校验优惠券编码格式（两位大写字母 + 四位数字）
- 输入：code: str
- 输出：bool
- 规则：格式合法返回 True，否则返回 False；非字符串或空值抛 ValueError
- 样例：`"AB1234"` → `True`；`"ab1234"` → `False`
- 类别：功能

### FP-05 分摊金额 split_payment
- 描述：把订单金额按人数均分并保证合计与总额完全一致
- 输入：total: str|int|float|Decimal, parts: int
- 输出：List[Decimal]（长度等于 parts，两位小数）
- 规则：余数以 0.01 为单位分给前几份；parts≤0 或非整数抛 ValueError；总额为负抛 ValueError
- 样例：`(100, 3)` → `[33.34, 33.33, 33.33]`；`(0.01, 2)` → `[0.01, 0.00]`
- 类别：功能

### FP-06 订单总价 order_total
- 描述：综合商品明细、会员等级、优惠券与运费计算订单应付总额
- 输入：items: list[dict]（每项含 price/quantity）, level: str, region: str, weight_kg, coupon: str|None
- 输出：Decimal（两位小数）
- 规则：明细为空或字段缺失抛 ValueError；数量必须为正整数；先按会员折扣、再抵扣优惠券固定金额 5 元（券码非法抛 ValueError），最后叠加运费；总额下限 0
- 样例：`([{"price": "100", "quantity": 2}], "VIP", "上海", "1.5", "AB1234")` → `170.00`
- 类别：功能

### FP-07 订单校验 validate_order
- 描述：校验订单结构，返回错误描述列表
- 输入：order: dict
- 输出：List[str]（合法时为空列表）
- 规则：必填字段缺失、明细为空、数量≤0、等级非法、重量≤0、地区为空均记入错误列表；订单非 dict 抛 ValueError
- 样例：`({})` → 至少 1 条错误；合法订单 → `[]`
- 类别：功能

## 4. 异常与边界要求（重要）

- 全部函数对非法类型必须抛出 ValueError，禁止静默吞错
- 边界：0 值、恰好 1kg、0.01 元、不可整除分摊、超大金额（≥ 1e12）、空字符串、阈值临界值（t、t-ε、t+ε）

## 5. 验收标准

- 全部功能点实现且 `import order_pricing` 可用
- 功能 / 异常 / 边界三类用例全部通过（覆盖率 100%）
- 无阻塞级代码审查问题，全部缺陷闭环
- 待澄清问题在交付前完成协商闭环并写入技术方案
