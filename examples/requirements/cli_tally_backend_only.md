# 文本统计工具（只要后端）需求文档

## 1. 目标

tally 是一个纯 Python 标准库文本统计命令行/库工具，用于对照验证流水线的意图识别：**本需求只做后端，不需要前端，不要任何页面、HTML、浏览器交互**。

## 2. 功能点

| 编号 | 功能点 |
|---|---|
| FP-01 | `count_words(text) -> dict`：按空白与常见标点切词，返回词频字典，大小写不敏感 |
| FP-02 | `top_k(text, k) -> list[tuple[str,int]]`：按频次降序返回前 k 个词，同频按字典序 |
| FP-03 | `readability(text) -> dict`：返回字符数、词数、句子数、平均词长（句子按 `.!?。！？` 切分） |
| FP-04 | `analyze_file(path) -> dict`：读 UTF-8 文本文件，文件不存在抛 `FileNotFoundError` 子类 `TallyError` |
| FP-05 | 空输入与纯空白输入返回全零结果，不抛异常 |

## 3. 约束

- 仅标准库；纯函数式 API，无网络、无 HTTP 服务、无 UI。
- 覆盖 FP-01~FP-05 的测试用例，含边界（空串、单个词、超长文本、混合中英文标点）。

## 4. 交付形态声明

交付形态 `backend_only`：仅库/CLI 交付，无任何前端产物。
