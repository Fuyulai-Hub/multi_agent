# 单页计数器小应用（counterweb）需求文档 —— SPA 门禁探针

## 1. 背景与目标

交付一个纯前端单页计数器小应用：页面逻辑全部在浏览器里运行（HTML + 原生 JavaScript），
后端只允许一个用于本地预览的静态文件服务。本需求用于验证流水线对「浏览器前端」交付的
门禁行为：交付形态必须由沙箱真实文件探测判定，浏览器级 UI 证据缺失时如实判失败。

## 2. 技术约束

- 前端：纯静态文件交付 `index.html` + `app.js`（可加 `styles.css`），禁止构建工具与第三方依赖
- 页面为客户端渲染：计数与按钮状态由 `app.js` 在浏览器里更新 DOM，服务端不渲染业务内容
- 预览服务：`serve.py`（Python 3.9+ 标准库 `http.server`），绑定端口 0，监听成功后在
  stdout 打印一行 `MAS_UI_PORT=<实际端口>`，随后持续服务当前目录静态文件直至被终止
- 计数展示节点固定为 `<span id="count">`，按钮 id 固定为 `btn-inc` / `btn-dec`

## 3. 功能点

### FP-01 页面初始状态
- 描述：打开首页显示初始计数与两个按钮
- 输入：GET / 返回 index.html
- 输出：HTTP 200，页面含 `id="count"`（初始文本为 0）、`id="btn-inc"`、`id="btn-dec"`
- 规则：初始计数为 0；页面引用 `app.js`
- 样例：GET / → 200 且响应体含 `id="count"`
- 类别：功能

### FP-02 点击加一
- 描述：点击「+1」按钮后计数加一并更新 DOM
- 输入：点击 `#btn-inc`
- 输出：`#count` 文本从 0 变为 1
- 规则：多次点击累加；不刷新页面
- 样例：点击 2 次后 `#count` 文本为 "2"
- 类别：功能

### FP-03 点击减一
- 描述：点击「-1」按钮后计数减一并更新 DOM
- 输入：点击 `#btn-dec`
- 输出：`#count` 文本减 1
- 规则：允许负数（教学用途，不做下限钳制）
- 样例：从 0 点击 1 次「-1」后 `#count` 文本为 "-1"
- 类别：功能

## 4. 验收标准

- AC-01：浏览器打开首页可见计数 0 与两个按钮（浏览器级证据）
- AC-02：点击 +1 / -1 后 `#count` 文本按规则变化（浏览器级证据）
- AC-03：GET / 返回 200 且响应体含 `id="count"` 与 `app.js` 引用（HTTP 证据）
