# 星选商城 StarMart · 电商前端演示

一个开箱可用的电商网站：商品浏览 / 搜索筛选 / 购物车 / 优惠码 / 下单 / 订单管理 / 后台运营，全部在浏览器里跑，不依赖服务端与网络。

## 打开方式

| 方式 | 操作 | 说明 |
|---|---|---|
| 直接打开 | 双击 `index.html` | 已实测 `file://` 可用，样式与脚本正常加载 |
| 本地服务 | `python -m http.server 8123` 后访问 `http://127.0.0.1:8123/` | 与 `file://` 行为一致，便于手机同网段访问 |

数据保存在浏览器 `localStorage`（键 `starmart.v1`），刷新、关闭浏览器后仍在；「管理后台 → 重置演示数据」可一键恢复初始 19 个 SKU。

## 功能清单

**商城（买家）**
- 19 个种子商品，5 个分类；按关键字搜索名称 / 分类 / 描述 / 标签
- 价格区间、仅看有货、5 种排序（综合 / 销量 / 价格升降 / 评分）
- 商品详情弹窗：规格、库存、数量选择、立即购买
- 购物车抽屉：数量步进（受库存上限约束）、单品删除、清空、实时小计
- 优惠码：`SAVE10`（满 100 减 20）、`NEW30`（满 300 减 30）、`VIP9`（满 500 九折，最多减 100）
- 结算：收货信息校验（姓名 / 11 位手机号 / 地址长度）、标准配送（满 99 包邮）与次日达（+¥15）
- 下单：按当前库存扣减、生成订单号、订单入库；库存不足会拦下并提示具体商品
- 我的订单：状态流转（待发货 / 已发货 / 已完成 / 已取消）、取消订单自动返库、再次购买

**管理后台（卖家）**
- 指标卡：在售 SKU、库存总量、订单数、成交金额
- 新增商品（名称 / 分类 / 价格 / 库存 / 图标 / 标签 / 描述）
- 商品表格内联改价、改库存，上下架、删除（下架与删除会同步移出购物车）
- 订单流水：发货、完成、取消

## 文件结构

```
index.html    页面骨架（四个视图 + 购物车抽屉 + 两个弹窗）
styles.css    设计令牌、布局、响应式（1080 / 860 两档断点）
app.js        数据层（localStorage）+ 渲染 + 事件委托，IIFE 无全局污染
.selftest.html 自动化 UI 自测（iframe 驱动真实点击，见下）
```

## 自动化自测

```bash
python -m http.server 8123          # 在本目录下启动
# 浏览器打开 http://127.0.0.1:8123/.selftest.html
```

自测页会在 iframe 里真实点击主页面，断言搜索、分类筛选、加购、数量步进、优惠码金额、
下单扣库存、取消返库、后台新增商品等 27 项，并把 PASS/FAIL 与结论渲染在页面上。
无头浏览器跑法：

```bash
chrome --headless=new --virtual-time-budget=15000 --dump-dom http://127.0.0.1:8123/.selftest.html
# 页面标题为 SELFTEST-OK 即全绿
```

## 已知边界

- 没有服务端：多设备不共享数据，清浏览器数据会回到种子状态。
- 没有账号体系：买家与卖家视图靠导航切换，不做权限。
- 商品封面用「渐变 + emoji」，避免外链图片失效；换成真实图片只需把 `emoji` 换成 `<img>`。
